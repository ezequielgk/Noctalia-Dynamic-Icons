# noctalia-dynamic-icons

Dynamic icons for GTK file managers (Nemo, Thunar, Nautilus, Caja). These scripts allow you to easily apply dynamic icons across different desktop environments.

---

## Available Themes

### Papirus
![Papirus Preview](img/papirus.png)
To install the Papirus theme, run the following command:
```bash
curl -fsSL https://raw.githubusercontent.com/ezequielgk/noctalia-dynamic-icons/main/papirus.sh | bash
```
